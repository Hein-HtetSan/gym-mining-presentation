Where the data came from

850 English exercise records collected from the public wger exercise catalogue.

  • Source: wger Workout Manager
  • Endpoint: Exercise Info API — English, 100 records per page
  • Collection script: workflows/fetch_exercises.py
  • Records were fetched with pagination and flattened into CSV; the raw JSON was preserved.
  • Record-level licence and author information are retained in the dataset.

Citation: wger Workout Manager. Exercise catalogue and public Exercise Info API. https://wger.de/

Frequent patterns

What occurs together?

Example: Chest category → Chest muscle

  • Support: how often both occur
  • Confidence: how often B occurs when A occurs
  • Lift: strength compared with chance
Association describes co-occurrence, not cause and effect.
Code evidence · Association

Verify the rule with the formula

How it is calculated 
support = count(A and B) / N
confidence = count(A and B) / count(A)
lift = confidence / support(B)

if support >= 0.02 and confidence >= 0.40:
    keep_rule()
